01 Radiobutton

A radiobutton lets a person pick exactly one option out of a small set. All radiobuttons that share the same name attribute belong to one group, so selecting one automatically clears the others. Use it when the choices are mutually exclusive and few enough to show all at once. Author can set one answer as a default.

02 Checkbox

A checkbox lets a person turn a single option on or off, independently of the others. Unlike radiobuttons, any number of checkboxes in a group can be checked at the same time — zero, some, or all.

03 Text input

A text input is a single-line field where a person types free-form text — a name, a search term, an answer. A placeholder shows a hint inside the empty field, but it disappears once typing starts, so it should never replace a real label.

04 Tabs

Tabs group related content into panels and show only one panel at a time, saving space compared to placing everything on the page at once. Clicking a tab's title switches the visible panel without reloading the page.

05 Buttons

A button triggers an action when clicked — submitting a form, opening a dialog, deleting an item. Its label should name the action itself ("Delete", "Submit"), and its visual weight should hint at how significant or reversible that action is.

06 Text Label

A text label is static text that names or describes another element on the page — a field, a status, a section. When a <label> tag's for attribute matches an input's id, clicking the label also focuses that input.

07 Link

A link (anchor, <a>) takes a person to another page, another section of the same page, or an external resource. Unlike a button, a link's job is always navigation, not performing an action.

08 Tooltip

A tooltip is a small popup that appears on hover or keyboard focus to give extra context without permanently taking up space on the page — a definition, a hint, or the full text of a truncated label.

Hover over this text This is a custom CSS tooltip — it appears on hover or keyboard focus.

09 Dropdown List

A dropdown (<select>) collapses a list of options into a single closed field, expanding only when clicked. It is useful when there are too many options to show all at once as radiobuttons.

10 Data Grid

A data grid displays information in rows and columns, so many records can be scanned and compared at once. Real-world data grids usually add sorting, filtering, or pagination on top of a plain table.
